# ALTIOR - GitHub Pages

Sitio estático responsive compuesto por `index.html`, `proposito.html`, `union.html` y `unete.html`.

## Publicar
1. Sube todo el contenido de esta carpeta a la raíz del repositorio.
2. En GitHub abre **Settings > Pages**.
3. Selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Guarda.

## Formularios
Los formularios usan `mailto:`: validan los campos y abren la aplicación de correo del visitante con el mensaje preparado. No almacenan información en GitHub. Para recepción automática, conéctalos después a un servicio de formularios o backend.

## Imágenes
Las imágenes fueron renombradas dentro de `assets/images/`. Sustituye cualquiera conservando el mismo nombre para actualizarla sin cambiar el HTML.

## Navegación verificada
- Menú de páginas internas vuelve a secciones de `index.html`.
- Propósito, Unión y Únete son páginas independientes.
- Enlaces externos abren en pestaña nueva.
